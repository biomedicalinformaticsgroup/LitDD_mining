Supplementary Data 1-7 for "PubMed-wide Classification and Disease-level Mapping of Peer-reviewed Literature for Genetic Developmental Disorders in Gene2Phenotype" (Yates et al., Nature Communications NCOMMS-26-018174A-Z).

UTF-8 CSV files with a header row; numbering as in the manuscript and Supplementary Information.

Supplementary Data 1: annotated set: (PMID, DDG2P entry) labels with titles (abstract text omitted; retrieve by PMID), with the label corrections applied (40 co-reported rows added; 69 corrected or added rows flagged in label_corrected) and rows for entries retired from G2P since annotation flagged (41, g2p_entry_retired)
Supplementary Data 2: released map: one row per paper with its DDG2P entries
Supplementary Data 3: DDG2P panel of 24 June 2026 used throughout
Supplementary Data 4: released-map precision audit: verdicts, strata, error categories and notes
Supplementary Data 5: rejected-mapping audit verdicts
Supplementary Data 6: inter-annotator audit labels with record type
Supplementary Data 7: curated papers not used in training or testing classified by rule as review articles or likely pre-molecular reports, with screen and pipeline outcomes
